# Agent lessons

- L12 [2×, last 2026-11-13, #3] When writing test fixtures that look like real secrets (`sk`-style keys): build them at runtime from low-entropy pieces (e.g. `common::fake_key`, `"harness".repeat(3)`) instead of committing literals (`scripts/preflight-secrets.mjs` scans tracked files and the CI gitleaks job scans commits, so a high-entropy join still turns CI red).
- L13 [2×, last 2026-11-13, #3] When prose (a doc, a comment, a lesson) must name a secret-like prefix: write it so the preflight scanner cannot match it (e.g. `sk`-style), because the scan covers every tracked file and a single lesson line turned `checks` red on HEAD.
- L49 [1×, last 2026-11-16, #22] When polling for an asynchronous condition in a browser test: allow a multi-second budget (e.g. 15 s) with ≥50 ms intervals (cold browser launch in CI takes seconds, causing false timeouts on sub-second budgets).
- L50 [1×, last 2026-11-17, #49] When an async route handler reads files or traverses graphs on disk: run the synchronous scans in `tokio::task::spawn_blocking` (synchronous filesystem I/O blocks Tokio worker threads from processing requests).
- L51 [1×, last 2026-11-17, #25] When a change deletes or moves a path: grep the whole repo for the old path before finishing, including files the change does not touch (an untouched `include_str!` and two fixture copies broke the `cargo test` build, and a stale path constant silently fell back to the bundled default).
- L52 [1×, last 2026-11-17, #25] When a test greps the repo for a forbidden string: exclude the test file itself with `:(exclude)<path>` (the guard's own GONE list contains the literal, so the grep matches the test and it fails on itself).
- L53 [1×, last 2026-11-17, #25] When auto-relaunching a spawned backend: surface the close code and relaunch only on 0, reporting any other exit (relaunching on any exit turns a crash into a silent restart loop with no error).
- L54 [1×, last 2026-11-17, #25] When a change removes, renames or adds a command, script, convention or path: update the agent docs that state it, prose file lists included (`AGENTS.md` and `docs/agents/*.md` name modules and scripts; a stale list survived two review rounds and misleads the next agent).
- L55 [1×, last 2026-11-17, #25] When a long-lived parent buffers a child's stdout/stderr: stop appending once the startup condition settles (the child keeps logging for the process lifetime, so the buffers and the per-chunk regex work grow unboundedly).
- L59 [1×, last 2026-11-17, #25] When a golden fixture embeds output derived from prose or generated files (parity goldens such as `context_parity system_prompt_replays_the_node_golden`): regenerate it in the same commit as the change that affects that output (a fixture green locally can still differ in CI; run the capture script and commit the refreshed fixture, don't hand-tune the diff).
- L56 [1×, last 2026-11-17, #25] When a script launches the desktop app that spawns the backend: set `PROXI_BIN` in the child env as `app/desktop/smoke.mjs` does (the app resolves the binary from its own environment, so without it the launch dies on "proxi binary not found").
- L57 [1×, last 2026-11-17, #25] When a check gates on drift from a stored baseline: give the limit an explicit override flag (a legitimate re-measurement after an intended change otherwise exits 1 even though the document is written and valid).
- L58 [1×, last 2026-11-17, #25] When code waits on an external process over a connection (CDP browser, child stdio): bound every wait yourself and treat a dead peer as immediate failure, replacing it (this chromiumoxide's command timeouts stop firing once the connection drops, so a browser death hung `cargo test` until the 35-min CI timeout killed the job).
- L60 [1×, last 2026-11-19, #60] When validating CLI arguments in a script: validate options and inputs before asserting external binary prerequisites (tests that check option validation fail in clean checkouts before argument parsing is reached).
- L61 [1×, last 2026-11-20, #60] When asserting paths printed by commands in tests on macOS: canonicalize the temp directory with fs::canonicalize (macOS /var is a symlink to /private/var, causing uncanonicalized paths to mismatch command output in CI).
