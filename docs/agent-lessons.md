# Agent lessons

- L12 [2×, last 2026-11-13, #3] When writing test fixtures that look like real secrets (`sk`-style keys): build them at runtime from low-entropy pieces (e.g. `common::fake_key`, `"harness".repeat(3)`) instead of committing literals (`scripts/preflight-secrets.mjs` scans tracked files and the CI gitleaks job scans commits, so a high-entropy join still turns CI red).
- L13 [2×, last 2026-11-13, #3] When prose (a doc, a comment, a lesson) must name a secret-like prefix: write it so the preflight scanner cannot match it (e.g. `sk`-style), because the scan covers every tracked file and a single lesson line turned `checks` red on HEAD.
- L17 [1×, last 2026-11-14, #6] When capturing a Node CLI's output into a golden replayed on another OS: pin only the platform-neutral part of OS-dependent text (e.g. the ENOENT prefix) and assert the per-platform tail in a `cfg!`-gated test (Node prints the resolved path on Windows but the argument as typed on POSIX, so a Windows capture turns the Linux CI red).
- L18 [1×, last 2026-11-14, #6] When reading a fixed byte range of a path or other string (`&path[1..2]` for a drive letter): check `as_bytes().get(n)` or a char boundary first (a multibyte character panics and the CLI dies instead of writing the lesson).
- L19 [1×, last 2026-11-14, #6] When a test fixture needs an absolute path: use a neutral root like `C:/data/...`, never a real user-home path (`tests/repo-meta.test.ts` and `scripts/preflight-secrets.mjs` scan every tracked file for personal paths).
- L20 [1×, last 2026-11-13, #9] When a request handler writes shared state after an await: re-check the cancel token or epoch under the same lock as the canceller before writing (a cancel that lands during the await otherwise leaves stale pending state forever).
- L32 [1×, last 2026-11-14, #4] When hand-porting a JS regex or scan to Rust: mirror the reference traversal exactly (one alternation pass with the earliest match winning, retry at `start + 1`, a stripped line keeps its newline) and test the exact Node output (two-pass stripping, dropped newlines and a `start + 3` skip each diverged and cost a fix round).
- L21 [1×, last 2026-11-14, #14] When reading a child process's stderr (or stdout) after the root exits: bound the read by the run's remaining timeout and abort the reader when it elapses (a descendant that inherited the pipe keeps it open, so the request hangs forever).
- L22 [1×, last 2026-11-14, #14] When resolving an executable on PATH: on Windows accept only `<name>.exe`, never an extensionless file (Windows cannot launch extensionless files, so an npm shim named `node` shadows the real `node.exe` and every run fails).
- L23 [1×, last 2026-11-14, #14] When rejecting a request by `content-length` before reading its body: drain the body before answering the error (an unread body resets the connection and the client sees `ECONNRESET`).
- L24 [1×, last 2026-11-14, #14] When adding a body validator in `server.rs`: parse through the shared `body_object`/`required_string` helpers and reuse `COURSE_PATTERN` instead of re-implementing the type match or repeating the literal (duplicated validation drifts and review sends the change back).
- L33 [1×, last 2026-11-14, #13] When porting a JS `for...of` over a JSON value to Rust: treat a string as iterable of one-character values and keep the throw for numbers, booleans, objects and null, with a success and a failure test per shape (Node returned 0 cards for a string `nodes` where Rust threw `not iterable`, so the failure boundary diverged and cost a fix round).
- L26 [1×, last 2026-11-14, #13] When an output line or a minted file path must match Node's `path.join`: build it with the lexical join helper (`crate::lesson::node_path::join`) and assert the exact printed path, never `Path::join`/`PathBuf::push` (`Path::join` keeps `./` and `..`, so `--base-dir ./out` printed `./out/decks/...` where Node printed `out/decks/...`).
- L30 [1×, last 2026-11-14, #10] When a Unix test writes an executable script and then runs it while other test threads may fork: retry that spawn on `Text file busy` (a concurrent fork holds the script's write fd until its own exec, so `install_through_a_bin_shim` passed locally and failed on CI).
- L31 [1×, last 2026-11-15, #24] When reading a Windows child process's stdout from `powershell` (Windows PowerShell 5.1): prefix the script with `[Console]::OutputEncoding=[Text.Encoding]::UTF8` and refuse to write the value back if it still contains U+FFFD (PS 5.1 encodes stdout in the OEM code page, so a non-ASCII `Path` entry was decoded as UTF-8, came back as U+FFFD and would have been written back, corrupting unrelated PATH entries).
