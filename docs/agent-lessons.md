# Agent lessons

- L12 [2×, last 2026-11-13, #3] When writing test fixtures that look like real secrets (`sk`-style keys): build them at runtime from low-entropy pieces (e.g. `common::fake_key`, `"harness".repeat(3)`) instead of committing literals (`scripts/preflight-secrets.mjs` scans tracked files and the CI gitleaks job scans commits, so a high-entropy join still turns CI red).
- L13 [2×, last 2026-11-13, #3] When prose (a doc, a comment, a lesson) must name a secret-like prefix: write it so the preflight scanner cannot match it (e.g. `sk`-style), because the scan covers every tracked file and a single lesson line turned `checks` red on HEAD.
- L24 [1×, last 2026-11-15, #15] When a test needs Node or another external prerequisite: make its helper panic like `common::require_node()` instead of printing "skipping" and returning false (the golden test went green without checking anything).
- L31 [1×, last 2026-11-15, #24] When reading a Windows child process's stdout from `powershell` (Windows PowerShell 5.1): prefix the script with `[Console]::OutputEncoding=[Text.Encoding]::UTF8` and refuse to write the value back if it still contains U+FFFD (PS 5.1 encodes stdout in the OEM code page, so a non-ASCII `Path` entry was decoded as UTF-8, came back as U+FFFD and would have been written back, corrupting unrelated PATH entries).
- L40 [1×, last 2026-11-15, #23] When building a spawned process's startup error from its stderr: settle on `close`, not `exit`, and drop any delay a test added to make the message appear (Node emits `exit` before the last stdio chunks arrive, so a binary that dies at startup loses the diagnostic that explains why).
- L34 [1×, last 2026-11-15, #18] When a second ported module needs a helper the crate already has (`js_type`, `invalid_type`, the `ask`/`quiz` option helpers, `vitest::truncate_utf16`, `course_data::progress_file`): make the existing one `pub(crate)` and call it there, never paste a copy into the module (byte-identical copies in `ask`/`quiz`/`lessontext`/`write_node`/`sessions` drifted and cost a fix round).
- L34 [1×, last 2026-11-15, #20] When a Rust port must reproduce a default of Node's request parsing (mime type, part name): read it off Node's own server and keep one test that runs against both (a Rust-only test only encodes the guess, and WHATWG `formData` gives a part with no `Content-Type` `text/plain`, not `application/octet-stream`).
- L35 [1×, last 2026-11-15, #18] When a tool and the document writer both stamp the same object (`capturedAt`): let the writer stamp it and return the object, then emit that one, never a pre-stamped copy (a second `iso_now()` differed by a millisecond, so the chat item and the `#lesson-data` island disagreed).
- L36 [1×, last 2026-11-15, #18] When a test proves an operation touches only its own ids (`abort`/`cancel`): assert the others stay untouched while the target is still armed (the r1 test aborted a call that had already completed, so it stayed green with the scoping removed).
- L37 [1×, last 2026-11-15, #20] When production code must arm a timer or spawn a process: cover the arming through the caller, not only the handler it calls (`turns.rs` tests called `watchdog_fired` directly, so deleting `spawn_delayed(WATCHDOG, …)` from `SessionManager::interrupt` left every test green).
- L38 [1×, last 2026-11-15, #20] When matching a Node `path` function in Rust: pin the Node output on edge inputs before writing the port (`path.win32.basename("C:foo.png")` is `"foo.png"`: it drops the drive designator, so a split on separators returned the whole name).
- L39 [1×, last 2026-11-15, #20] When a test kills or restarts the server after a state change: wait for the debounced on-disk flush (`state.json`) before closing (`sessions.rs` flushes it 300 ms late, so a restart inside that window loaded a stale `running` turn).
- L41 [1×, last 2026-11-15, #19] When porting Node's `execFile` failure text to Rust: always end `Command failed: <cmd>` with a newline before the possibly empty stderr and pass the stderr read so far on timeout (Node appends the newline even when stderr is silent, so the status error string diverged and cost a fix round).
- L42 [1×, last 2026-11-15, #19] When a Rust spawn helper can fail before `Command::spawn` (scratch dirs, files): map only the `spawn()` error to Node's `spawn <program> ENOENT` and keep the real io error for setup failures (a filesystem `NotFound` was reported as a missing executable).
- L43 [1×, last 2026-11-15, #19] When a binary-mode test restarts the `proxi` server: wait until `state.json` holds the expected state and matches the live session before closing it (a killed process skips the debounced save, so the restart reloaded stale state and the test flaked 4 runs in 5).
- L44 [1×, last 2026-11-15, #19] When a test removes a temp folder on Windows after killing a server: use a bounded retry helper instead of `rmSync(maxRetries: 3)` (the killed engine child holds the folder past its ~475 ms budget and teardown failed with EPERM).
- L45 [1×, last 2026-11-16, #21] When preserving an existing plan's slug across re-planning: ignore an empty slug so it falls back to the title's slug (`planned_lessons` turns a missing legacy slug into `""` where Node had `undefined`, so keeping it failed validation).
