# Issues and roadmap
- Work items are GitHub issues. Write new ones with the from-ideas-to-issues skill; it owns the template and the sizing rule.
- Labels: `bug` | `enhancement` (category) + `ready-for-agent` | `ready-for-human` (state). Blocking uses GitHub's native "blocked by" links; dependencies are never expressed as a label.
- Milestones are titled `Mxx <name>` (two digits): title order is work order, the lowest open one is current. Each open one has a block in `docs/ROADMAP.md`, edited only with the moves in the comment at its top. Vision and milestone changes: the vision skill.
- Issues close through their PR (`Closes #N`).
